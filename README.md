# SynGAS — модель синтез-газа из природного газа на Ni/MgAl₂O₄

**Статус (26.10.2026):** V2 + V3 + V4 реализованы и запущены.
Пять целевых продуктов, оба определения нормального м³, две площадки,
регулируемая конфигурация, Peng–Robinson + IAPWS-IF97, адиабатический
предреформер, CO₂-трим метанола, контуры синтеза готового продукта,
скрининг безопасности Ni(CO)₄/HAZOP/PSV, независимая проверка SciPy SLSQP,
инвентаризация Ni/MgAl₂O₄. **Aspen HYSYS не запускался** — его нет в среде;
пользователь подтвердил Python/DWSIM-эквивалент (вопрос 11). Пять контуров
проверки: 1–4 **пройдены**, контур 5 (валидация/фальсификация) **не пройден** —
пилотные данные найдены и сравнены, но нет кампании на расчётной точке
20–31 бар, коммерческого даташита Ni/MgAl₂O₄ и сертифицированного HAZOP.
Работа **не объявляется завершённой**.

## Быстрый запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt       # ядро — чистый stdlib; пакеты нужны для IF97/графиков/панели/SciPy
PYTHONPATH=. .venv/bin/python -m model.run_v2  # ~4 мин -> results_v2/ + docs/12..25
PYTHONPATH=. .venv/bin/python -m pytest -q     # 37 тестов
PYTHONPATH=. .venv/bin/python -m model.run     # V1 (метанол, ~10 с) -> results/
```

Если `iapws` не установлен, модель автоматически переходит на NIST Shomate +
Antoine и явно помечает это в `results_v2/summary_v2.json`.

## Живая панель управления (регулировка, вопросы 2/7)

```bash
PYTHONPATH=. .venv/bin/python -m web.app        # 0.0.0.0:5000, Arena live preview
```

В браузере: выбор продукта / нормального м³ / площадки / сырья / набора kᵢⱼ /
таблицы пара, ползунки S/C, CO₂/C, O₂/C, T, p, approach, срока службы и
содержания Ni, GHSV, плотности, цен газа/электроэнергии/CO₂/пара, а также поле
**произвольных точечных переопределений JSON** (PSA/WGS/MDEA/воздух/трим).
Вкладки: спецификация, утилиты, катализатор/Ni, оборудование, экономика,
сравнение/графики, JSON, **синтез**, **безопасность**. Браузер обращается только
к относительным `/api/*` — никаких `localhost`.

CLI (без браузера):

| Продукт | Метрика / цель | Достигнуто | Ni, т | Товарный продукт | Стоимость |
|---|---|---|---|---|---|
| метанол | SN 2,05; CO₂ 4–8 % | 2,0500 / 6,00 % | 10,59 | 40,2 т/ч CH₃OH | 262 USD/1000 нм³ СГ |
| Фишер–Тропш | H₂/CO 2,10 | 2,1000 | 6,79 | 12,9 т/ч C₅₊ | 214 USD/1000 нм³ |
| оксо | H₂/CO 1,05 | 1,0500 | 3,30 | 66,0 т/ч альдегида | 254 USD/1000 нм³ |
| водород | 99,97 % H₂ (ISO 14687) | 0,99970 | 11,86 | 9,0 т/ч H₂ | 365 USD/1000 нм³ H₂ |
| аммиак | H₂/N₂ 3,00 | 3,0012 | 10,18 | 47,4 т/ч NH₃ | 600 USD/т NH₃ |

- **[ПОДТВЕРЖДЕНО]** CO₂ окно метанола 4–8 мол.% (Appl. Sci. 2017 7,1213) закрыто
  частичным MDEA-тримом при CO₂/C = 0,7615; рост стоимости 225 → 262 USD/1000 нм³.
- **[ЧАСТИЧНО]** синтез: метанол 25–30 % за проход + рецикл 3:1, FT α = 0,90 и
  70 % CO, NH₃ 18 % за проход и 97 % суммарно; это стехиометрия, не кинетика.
- **[ЧАСТИЧНО]** безопасность: log₁₀K = 7430/T − 21,90 для Ni(CO)₄;
  при работе 0,0006 ppb, при останове нужна продувка CO < 10 ppm до 200 °C.
- **[ПОДТВЕРЖДЕНО]** независимый SciPy SLSQP с PR-фугитивностью: max |Δy| = 1,1·10⁻⁸.
- **[ЧАСТИЧНО]** Δp Эргуна исправлен (Па → бар) и число труб поднято с 231 до 509,
  чтобы выдержать ≤ 3 бар.

Небаланс по элементам ≤ 1,6·10⁻¹² %, по арифметике ≤ 1,8·10⁻¹⁶ (отн.),
Q·Kφ/K = 1 с погрешностью ≤ 10⁻¹¹ %. Переход 0 °C → 15 °C меняет все
объёмные потоки на +5,49 % при том же молярном заводе.

## V4: пилотные данные, кинетика, HAZOP, перезапуск контура 5

**Что реально получено (без выдуманных чисел):**
- 30 записей из 7 открытых источников по 15 мас.% Ni/MgAl₂O₄ — свойства,
  кинетика, 100‑часовые испытания, X_CH₄ от p и T, 200‑минутные ряды
  дезактивации (`data/pilot_ni_mgal2o4.json`).
- Коммерческие даташиты **носителя** MgAl₂O₄ (Novotech, Baikowski,
  Sigma‑Aldrich, Sasol). Даташит именно **Ni/MgAl₂O₄ катализатора НЕ найден** —
  прокси JM KATALCO (α‑Al₂O₃/Ca‑алюминат) оставлен и явно помечен.
- Кинетика метанола VBF/Graaf (первичная статья с таблицей параметров открыта):
  за проход 30,2 %, бенчмарк Арзева 3,09 против 3,4 мол.% MeOH (−9 %).
- Кинетика NH₃ Temkin–Pyzhev/Dyson–Simon (α=0,654, Ea=159,4 кДж/моль):
  8,8 % за проход — **честно занижено** относительно 15–25 %; для 13 мол.% NH₃
  нужен GHSV ≈ 1000 ч⁻¹ вне открытого диапазона. Скрытый η не вводился.
- HAZOP: 10 узлов × 11 направляющих слов = 110 строк, 20 с высоким риском.
  **НЕ СЕРТИФИЦИРОВАНО** — нет команды, facilitator, P&ID, LOPA/SIL, подписей.

**Контур 5 перезапущен:** внешние данные сравнены, среднее смещение
равновесной модели относительно кинетических измерений **+0,287 X_CH₄**
(6 численных точек). Тренд по давлению воспроизведён. Из 13 подпроверок
проходят 4. Контур 5 остаётся **FAIL**, модель не объявляется завершённой.
