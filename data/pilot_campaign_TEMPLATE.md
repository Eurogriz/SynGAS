# Шаблон файла питотной кампании (V5)

`pilot_campaign_TEMPLATE.csv` содержит **только строку заголовков**: данных нет,
и быть не должно — этот файл не результат измерений, а форма для них.

Правила заполнения — `docs/27_v5_pilot_test_program.md`; машиночитаемый
контракт (типы, единицы, диапазоны, обязательные поля) — `data/pilot_schema.json`.

После заполнения:

```bash
PYTHONPATH=. .venv/bin/python -m model.data_ingest --file data/my_campaign.csv
```

Команда проверяет контракт (единицы! кельвины, бары абсолютные, нормальные м³),
считает равновесную модель в условиях каждой точки, оценивает Δp против Эргана,
разбирает series_id в ряды спекания и печатает статус трёх подпроверок контура 5.
Отчёты: `results_v2/pilot_ingest_report.json`, `results_v2/pilot_ingest_records.csv`.

Обязательный минимум, иначе подпроверки не сдвинутся: 24 точки конверсии в окне
20–31 бар / 1023–1173 K (половина — с удвоенным расходом для разделения
кинетики и равновесия), 12 точек Δp только по слою, ≥ 2 ряда спекания по
0/200/500/1000 ч с TEM/BET и коксом.
