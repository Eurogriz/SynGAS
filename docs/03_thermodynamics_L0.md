# G2. Термодинамика (L0) — метод, источники, результаты

## 1. Метод

Минимизация энергии Гиббса при фиксированных T, p и инвентаре элементов
(C, H, O, N) на чистом Python (`model/equilibrium.py`), без HYSYS/Cantera/SciPy в ядре.
Фазы: 8 идеальных газов (CH₄, C₂H₆, H₂O, CO, CO₂, H₂, O₂, N₂) + твёрдый графит
(активность = 1, без члена смешения). 9 веществ − 4 элемента = 5 степеней свободы:
R1 SMR, R2 WGS, R3 окисление H₂, R4 гидрогенолиз C₂H₆, R5 крекинг CH₄ → C + 2H₂.

G = Σ nᵢ[gᵢ°(T) + RT ln(yᵢ p/p°)] + n_C·g°_C(T), p° = 1 бар.
Минимизация — метод Ньютона в координатах реакций с аналитическим гессианом,
дробным шагом к границе и поиском по прямой (Armijo). Стадия 1 — газовая; стадия 2
включает графит, если аффинность углерода
Δμ_C = μ(CH₄) − 2μ(H₂) − g°(графит) > 0.

**Термоданные.** Основной набор — Shomate из NIST WebBook / NIST-JANAF (Chase 1998),
открытые страницы S01–S07; H₂O(l) — S08; Antoine для точки росы — S09; C₂H₆ и графит —
NASA7 (S12, S13). Независимый набор — NASA7 GRI-Mech 3.0 для всех газов (S13).

**Явные допущения.**
- Идеальный газ при 20–40 бар. Проверено Peng–Robinson (k_ij = 0, критические свойства S14):
  Z = 1,0029, поправка K_φ для R1 = **+1,73 %**, для R2 = **+0,37 %** при 1123 K/25 бар.
  Это находится внутри точности front-end, но для рабочего проектирования нужен PR/SRK в HYSYS.
- H₂O(g) Shomate 500–1700 K экстраполирован до 298 K (S02); погрешность внесена в риск R-04.
- Графит как единственная твёрдая фаза: нитевидный/инкапсулирующий/пиролитический кокс,
  кинетика коксования и локальные условия в порах **не моделируются**. Граница necessary but not sufficient.

## 5. Граница термодинамической устойчивости графита

`results/carbon_boundary.csv`: критическое S/C, при котором Δμ_C = 0, для
T = 873/1023/1173 K, p = 5/25/40 бар, CO₂/C = 0 и 1. Интерпретация:

- При S/C = 3 и T ≥ 873 K, CO₂/C ≤ 1 аффинность Δμ_C **отрицательна** — графит
  термодинамически нестабилен (базовый кейс: Δμ_C ≈ −13…-20 кДж/моль).
- При S/C → 0 и CO₂/C = 1 (чистый DRM) графит **стабилен**: маршрут DRM в
  `results/routes_summary.csv` имеет `carbon_stable = true`, X(CH₄) = 0,750.
- При S/C < ~2 при 873 K и 40 бар риск растёт; lowering S/C требует обоснования
  с учётом кинетики коксования и C₂₊ (C₂₊ в модели перерабатываются в пре-риформере).

**Вывод.** Чистый SMR даёт SN = 2,93 — слишком водород-богатый газ для метанола.
Нужно либо импортировать CO₂ (найдено CO₂/C = 0,2468), либо ставить ATR/вторичный
реформер, либо экспортировать H₂. ATR/POX дают SN < 2 и требуют ASU (245 кВт·ч/т O₂, S29).
DRM даёт H₂/CO ≈ 1,2, но термодинамически обречён на кокс в отсутствие пара.
Электрифицированный SMR термодинамически идентичен обычному; зрелость [НЕ ПОДТВЕРЖДЕНО].
