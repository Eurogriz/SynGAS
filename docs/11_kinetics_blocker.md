# Блокер G5: кинетика L2 (Xu–Froment) — что реально сделано

## 1. Что реализовано

`model/kinetics.py`: LHHW-уравнения Xu–Froment для R1 (SMR), R2 (WGS), R3 (общая SMR)
и изотермический PFR с адаптивным шагом RK4. Параметры **не из памяти**, а из открытых
вторичных источников:

| Источник | Что дал |
|---|---|
| S44 — Fernandes & Soares, Lat. Am. Appl. Res. 36 (2006) 155–161 (PDF открыт) | полный набор: k₀ (4,2248·10¹⁵ / 1,955·10⁶ / 1,0202·10¹⁵), Ea (240,1 / 67,13 / 243,9), константы адсорбции K₀ и ΔH, константы равновесия K₁/K₂/K₃, геометрия реактора, кривая конверсии Fig. 5a |
| S43 — Abbas, Dupont & Mahmud, IJHE 2017 (open access PDF) | независимое воспроизведение Table 3 (Ea Xu–Froment 240,10 / 67,13 / 243,90 кДж/моль; k₀ 1,17·10¹² / 5,43·10² / 2,83·10¹¹), Appendix A (уравнения A1–A9), собственные эксперименты на 18 мас.% NiO/α-Al₂O₃, 1 бар, 550–700 °C |
| S15 — Crossref, DOI 10.1002/aic.690350109 | проверка библиографии первичной статьи; **полный текст не открыт** |

## 2. Обнаруженные противоречия вторичных источников (не сглажены)

1. S44 Table 1 озаглавлена «Ea or ΔH [J/mol]», но значения 240,1 / 67,13 / 243,9
   физически **кДж/моль**. Использованы кДж/моль, задокументировано.
2. S43 Appendix A использует индексацию k₃ для WGS и k₂ для общей SMR, тогда как
   S44 и классика Xu–Froment используют k₂ для WGS и k₃ для общей реакции.
   Индексация **несовместима** без первичного текста.
3. S43 Table 3 даёт k₀ Xu–Froment на 3 порядка меньше S44 при тех же Ea, в других
   единицах (моль·бар^0,5/(г·с) против моль·атм^0,5/(г·ч)).
4. S44 Table 3 даёт плотность катализатора 2355,2 «g_cat/m³» — физически это кг/м³.
   Обе интерпретации **запущены** в расчёте (`density_factor` 1 и 1000).
5. S44 Fig. 5a при 29 бар(а) показывает X(CH₄) 0,18/0,38/0,55/0,73/0,88/0,97
   при 750/800/850/900/950/1000 K, но при тех же условиях равновесие (наш NIST-код)
   даёт 0,082/0,134/0,199/0,280/0,379/0,494. Опубликованная кривая **выше равновесия**
   при 900–1000 K — физически невозможно для чисто термического SMR без отвода H₂.
   Вероятно, Figure 5a смешивает мембранный/обычный режимы или содержит опечатку.

## 3. Результат фактического запуска

| T, K | X опубликован | X наш (2355 г/м³) | X наш (2355 кг/м³) |
|---|---|---|---|
| 750 | 0,18 | 0,071 | 0,084 |
| 800 | 0,38 | 0,132 | 0,135 |
| 850 | 0,55 | 0,199 | 0,200 |
| 900 | 0,73 | 0,279 | 0,279 |
| 950 | 0,88 | 0,374 | 0,374 |
| 1000 | 0,97 | 0,485 | 0,485 |

Среднее абсолютное отклонение **0,356**, максимальное **0,506**. Лучшая интерпретация
плотности — кг/м³. Наши значения совпадают с **равновесием** NIST при 29 бар(а):
0,082 / 0,134 / 0,199 / 0,280 / 0,379 / 0,494. То есть PFR с этими скоростями
достигает равновесия и физически не может дать 0,97 при 1000 K и 29 бар(а).

## 4. Положительный результат (контур 4)

Константы равновесия K₁ и K₂ из S44 Table 2 совпадают с рассчитанными из NIST-JANAF
в диапазоне 750–1000 K в пределах **8 %** (K₁: 0,00362 против 0,00334 при 750 K;
1,303 против 1,297 при 900 K; 24,71 против 26,27 при 1000 K). Это независимое
подтверждение корректности термодинамического ядра.

## 5. Вывод

L2-кинетический код написан и запущен, но **не валидирован**:
- первичный текст Xu & Froment не открыт;
- вторичные источники противоречивы;
- опубликованная кривая не воспроизводится и, по-видимому, термодинамически
  несовместима с теми же условиями;
- оригинальная кинетика получена при 773–848 K и 3–10 бар, а проект — 1123 K и
  25 бар (**вне области применимости**).

По правилу 13 («не применять кинетику вне диапазона применимости») модуль
`model/kinetics.py` **не используется ни в одном проектном решении**. Он сохранён
как диагностический артефакт и как спецификация того, что нужно исправить после
получения B-01. Контур 5 остаётся **не пройденным**.
