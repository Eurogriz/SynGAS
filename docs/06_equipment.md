# G6. Оборудование: расчёт, альтернативы, листы данных

**Статус Standards:** API 530/560/520/521/610/617/618/661, API RP 941, TEMA,
ASME BPVC VIII, ASTM A608, NFPA 86, API 556 в этой сессии **не открыты** (S36).
Все формулы ниже — открытая инженерная методика с [ДОПУЩЕНИЕ]-параметрами;
**соответствие кодам не подтверждено**. Окончательный подбор — за поставщиком
и лицензиаром.

## 1. Подготовка сырья (E-101, HDS + ZnO)

Расчёт: S на входе 5 ppmv ⇒ 0,43 кг S/ч; при ёмкости 0,25 кг S/кг ZnO [ДОПУЩЕНИЕ],
плотности 1000 кг/м³ и сроке 2 года: **30 077 кг ZnO, 30,1 м³, D = 2,34 м, L = 7,01 м**.
Альтернативы: (A) один сосуд — риск проскока; (B) lead-lag + ультра-очистка —
<10 ppbv [S32], дороже. Требуется спецификация поставщика ZnO.

## 2. Пре-риформер R-101

Адиабатический равновесный реактор, 603,3 → 597,2 K; C₂H₆ перерабатывается в CH₄/CO₂/H₂.
Q = 0 по построению; объём слоя по GHSV **не рассчитан** (нет данных по катализатору
пре-риформинга). Альтернативы: (A) адиабатический слой; (B) без пре-риформера —
риск коксования по C₂₊ [S17]. Выбор A, но объём — блокер B-04.

## 3. Реформер R-201 (SMR)

Входные данные из L1: Q = 88 844 кВт. Принято [ДОПУЩЕНИЕ]: q = 80 кВт/м²,
ID = 0,10 м, L = 12 м, толщина стенки 12 мм, GHSV = 5000 нм³/(м³_кат·ч),
d_частицы = 10 мм, ε = 0,40, μ = 3·10⁻⁵ Па·с.

| Параметр | Значение |
|---|---|
| Площадь одной трубы | 3,77 м² |
| Число труб | **≈ 295** |
| Объём катализатора (GHSV) | 27,2 м³ (геометрия труб 27,8 м³) |
| Скорость газа (при 1123 K, 25 бар) | 2,72 м/с |
| ρ газа | 4,82 кг/м³ |
| Δp по Эргану, базовый вариант | **7,10 бар** |
| Критерий Δp ≤ 3 бар [ДОПУЩЕНИЕ] | **НЕ ВЫПОЛНЕН** |

**Альтернативы:**
A — верхний факельный радиационный бокс (зрелость высокая, NOₓ, 295 труб);
B — боковой/террасный обогрев (более плоский профиль теплового потока, 347 труб);
C — газонагреваемый/теплообменный реформер (US4919844A, S34; нет вендорных данных —
[НЕ ПОДТВЕРЖДЕНО]); D — электрифицированный (WO2019228797A1, S42; TRL [НЕ ПОДТВЕРЖДЕНО]).
Параметрическая альтернатива по Δp: 1,5× труб + d = 16 мм + ε = 0,50 →
**Δp = 0,84 бар** — выбрана как направление, но требует каталога гранул.

Расчёт толщины стенки на ползучесть по API 530/параметру Ларсона–Миллера
**не выполнен** (стандарт не открыт). Требуется: марка стали (HK/HP микролегированная),
T_стенки max 905 °C [ЧАСТИЧНО, S33], ресурс 100 000 ч [S28], запас на коррозию.

## 4. E-201 котёл-утилизатор

Q = 34 737 кВт, LMTD = 340,3 K (ΔT₁ = 450 K, ΔT₂ = 250 K — **пересечения нет**),
U = 60 Вт/м²/K [ДОПУЩЕНИЕ] ⇒ **A = 1702 м²**.
Альтернативы: A — жаротрубный WHB + паровой барабан (зрелый, риск металлического
пыления и напряжений в трубной решётке); B — водотрубный (лучше для пара высокого
давления, сложнее). Выбор A; риск metal dusting отмечен в docs/08.

## 5. E-202 охлаждение / V-201 сепарация

Q = 47 851 кВт; 4 121 м³/ч охлаждающей воды. Альтернативы: A — кожухотрубный
доохладитель + сепаратор (TEMA); B — аппарат воздушного охлаждения + доохладитель
(меньше воды, больше площади, чувствителен к климату EE). K-фактор и время
пребывания сепаратора **не рассчитаны** (нет вендорных данных) — блокер B-04.

## 6. Машины и ASU

- Компрессор сырья: политропный расчёт, 1150 кмоль/ч, 20→30 бар(а), η = 0,75,
  k = 1,30 [ДОПУЩЕНИЕ] ⇒ **≈ 0,7 МВт** (`results/equipment.json`). Альтернативы —
  центробежный (API 617) против поршневого (API 618); каталожные кривые не открыты.
- ASU: в базовом SMR O₂ не нужен (0 МВт). Для ATR/POX: 245 кВт·ч/т O₂
  при >99,5 % [S29] — [ЧАСТИЧНО], без учёта давления подачи.
- Насосы питательной воды (API 610) — не рассчитаны из-за отсутствия характеристики сети.

## 7. Невыполненные пункты раздела 9 правила

CO₂-очистка, PSA/мембраны, WGS/метанатор, колонные расчёты, факельная система,
LOPA/SIL, сбросы по API 520/521, NOₓ по горелкам — **не рассчитаны количественно**:
нет вендорных данных и лицензионных методик. Они перечислены в `docs/09` как блокеры,
а не заполнены оценками «из памяти».
