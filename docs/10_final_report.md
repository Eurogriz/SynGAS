# Итоговый отчёт (G9, промежуточный)

Дата: 26.10.2026. Ветка `arena/7cd84f1a-syngas`.

## 1. Краткий вывод

Построена и **фактически запущена** воспроизводимая front-end модель (L0/L1) получения
синтез-газа из природного газа на Ni/MgAl₂O₄:независимо от HYSYS, на чистом Python с
двумя независимыми наборами термоданных. Для базового кейса 100 000 нм³/ч метанольного
синтез-газа (SN = 2,00) при 850 °C, 25 бар(а), S/C = 3,0 требуется импорт
CO₂/C = 0,2468; конверсия CH₄ 78,4 %; балансы замкнуты (энергия 5,1·10⁻¹⁴ %,
элементы 4,4·10⁻¹⁴ %). Катализатор Ni/MgAl₂O₄ обоснован как базис, но его
**3-летний ресурс не валидирован**: две модели деградации расходятся в 3 раза.
Кинетика L2 реализована как диагностика, но **не воспроизвела** опубликованную кривую —
G5 заблокирован. Работа **не объявляется завершённой**: контур 5 не пройден.
